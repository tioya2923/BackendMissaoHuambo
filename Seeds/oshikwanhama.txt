CORO: Yesu Kristu, Mwene wange, / Ondekupandula, / Sasi owetufil'oñhenda, / N'ohonde wetukulila.
1. Tunyakukweni nena, / Yesu Okwanyumuka, / Oike vali twahala, / Ofye twemuitavela!
2. Eulu layeululwa, / Ovayuki vo nale, / Tavaimo, vanyakukwa, / Vakatale Kalunga.
3. Na fye hatukaya-mo, / Ngenge twalonga naua / Oipango ya Kalunga, / Ei tuu twapewa.
4. Vakristau vakwetu, / Tupanduleni atuse / Yesu Omwene wetu, / Tum’tumbalek’aluse.
114.	ANYUMUKA YESU
1. Tuhambeleleni / Kalung’Om’nañhono / Tuimbeni alleluya.
Anyumuka Yesu / Om’kulili wovañu / Tuimbeni alleluya.
2. Yesu anyumuka, / Akhupif’ounyuni, / Tuimbeni alleluya.
3. Afya k’ekulusu, / Nde nena anyumuka, / Tuimbeni alleluya.
4. Okwetukulila, / Afut’omatimba, / Tuimbeni alleluya.
5. Ata om’satana / N’ekulusu laye, / Tuimbeni alleluya.
6. Enyumuko laye / Oletukhupifa, / Tuimbeni alleluya.
7. Ye okwanyumuka / Oso tum’tambule, / Tuimbeni alleluya.
8. Fye hatukamona / Yesu Muene wetu, / Tuimbeni alleluya.
115.	YESU ETUKULILA
1. Yesu etukulila / M’ekulusu laye, / Om’satana atewa / Yesu otukulila / Tunyakukweni hano nena; / Etukandule k’oudyu waluse, / Etukhupife, aitavela ekulusu; / Olyelye hano itapandula, / Itahale Yesu omukulili.
2. Itaitila nande efyo, / Sasi Mwene wange Kristu / Nen’anyumuka, / Itaitila nande efyo: / Kalunga efyo okwelita, / Esi okwafya molw’ange, / Yesu akulila nge / Nohonde yaye iwa: / Amonifa nge / Nena ehafo lo m’eulu / Eli italipu.
116.	YESU ALONDA KU SE M’EULU
1. Yesu alonda ku Se m’eulu / Kombada yedu esi adya-ko, / Fiku lakhuninwa Ye om’tokoli, / Kombada yoilemo teuya vali.
2. Evalekela tati: indeni, / Muning’apese ovaitaveli, / Okuvaudifa mounyuni ause, / N’okumbatisala m’edina la Se.
3. Okwafiya-po ponele yaye, / Ongeleya ei naitupangele, / Tudulike ku yo, tumuitavele, / Endaka dosili yo idikwete.
4. Yesu ehole ovanu vaye, / Moikhuna yetu hetukoneke, / Ohetupopile pu Se Kalunga, / Atale oikhuna etumonena.
5. Hatukahanga Yesu m'eulu, / Fiku Kalunga efyo tatumu. / Tukale aluse m'ehafo laye, / Tupewe ofuto taidi k'Omwene.
117.	OMUNELAO TERESA
Omunelao, Teresa, / Om'holike womwene, / Tupwilikina nena, / Hatukuindile.
1. Diva, opo wadalwa / Weliyandya k'Omwene, / Yesu ekuhoolola / Ngas'okana kaye.
2. Wapitifa omwenyo / Okulonga aise iwa, / Wafa ngasi onemo / Taitoka m'omapya.
3. Ove natang'okana / Wahalika ku Yesu, / Ku Yesu Om'nañhenda / Wahokwa m'eulu.
4. Kalung'ekuhumbata, / Ekupaka m'eulu, / Ngasi watumbalekwa, / Teresa ya Yesu!
5. M'eulu omu waya, / Tufila-yo oñhenda, / Onemo yongalasa, / Mu fye ikoneka.
6. Avese ovatumwa / Vaning'endenge doye, / Vakwafela m'oikhuna / M'endyovo dOmwene.
7. Na fye, Meme Teresa, / Ila utukoneke, / Tukusikule nawa, / M'eulu tukuhange.
118.	ESANTU AMUSE
Esantu amuse muli m'eulu, / Hatumutumbaleke n'ehafo linene.
1. Ovapostolu mwatumwa ku Yesu, / Muudif'endyovo daye m'oilongo yovanu, / Twaitayela n'eñhono esi mwetulonga, / Nye mutupopile 'fiku lakhuninwa.
2. Nye ovahongi twemupandula, / Mwetuulikil'ondyila Kalunga ahala, / Ohatumuindile nye muli m'eulu, / Mutukoneke naua fye kombada yedu.
3. Nye mwadipaelwa molwa Kalunga, / M'eitavelo la Yesu mwadinina naua, / Tupeni-yo eñhono, tukondye ngasi nye, / Tutwaleni m'eulu efiku hatufi.
4. Nye ovakwetu mwakala sito, / Mun'omitima iwa kain'opekalo, / Twahal'okulandula omikalo yeni, / Tufewek'omitima m'eñhedi dombili.
5. Ovanelao opo kwafeni, / N'ovañu vetuyele tukale n'ombili, / Eongalo la Yesu nalininge limwe, / N'osunda simwe asike m'oilongo aise.
119.	TUINDILILE VAKWETU
1. Tuindilile vakwetu, / Vafya veli m'ombila / Diva vapite m'eulu, / Vo vafilwe oñhenda.
2. Oveli mo purgatoriu, / Tavamono oikhuna, / Fye n’omaindilo etu / Tuvaetel’oñhenda.
3. Olutu lapakwa m’edu, / Litelel’enyumuko / Mumwe n’omwenyo m’eulu, / Efiku lok’ekhunino.
4. Keembila dovafi vetu, / Tuyeni okuindila; / Ovakuetu p’efyo letu, / Na vo ihavetudimbwa.
5. Setuwapalela naua, / Tuindile p’Omissa, / Vafi vetu havakwafa / Ku Yesu mo Hostia.
6. Luhapu tudiladile, / Efiku lefyo letu, / M’omundilo tuhakaye / Fye tupite m’eulu.
120.	OVAKWA’OUNYUNI
Ovakwa’ounyuni, fileni oñhenda, / Ovakwa, ounongo tavemulilile / M’oikhuna yavo mô Purgatoriu.
1. Kalunga, Mwene efilonhenda, talaleka omayahamo / Avakwetu veli mo Purgatoriu.
2. Kalunga ’Mwene, vayavelela -utale oikhuna yevamonena / Yesu Kristu om’kulili wetu.
3. Kalunga, ’Mwene, vafil’oñhenda -utale oikhuna / Noilonga ei iwa ya Santa Maria, Meme yetu.
4. Kalunga, ’Mwene, vafil’oñhenda -utale oikhuna / N’oilonga ei iwa yesandu adise.
5. Kalunga, ’Mwene, vafil’oñhenda -vekekupandule / M’eulu fiyo fiyo.
